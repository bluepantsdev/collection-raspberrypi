pi-common
=========

Setup some basic raspberry pi settings.

Requirements
------------

This role is intended to be run on a Raspberry Pi running Raspbian.

Role Variables
--------------

See `defaults/main.yml` for a list of variables that can be set.

Dependencies
------------

None.

Example Playbook
----------------

Including an example of how to use your role (for instance, with variables passed in as parameters) is always nice for users too:

    - hosts: servers
      roles:
         - { role: bluepantsdev.raspberrypi, x: 42 }
